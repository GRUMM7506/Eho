# ЭХО

Браузерная 3D-головоломка. У каждой комнаты есть лимит времени; когда он кончается или вы
нажимаете «Записать эхо», попытка превращается в полупрозрачную копию, которая в следующих петлях
повторяет ваши ходы шаг в шаг. Решение собирается из команды собственных прошлых «я».

- 6 миров, 44 основных уровня + 3 бонусных (открываются за звёзды), финальный уровень на 5 копий.
- 16 механик: плиты и двери, инверсные двери, плиты эха и игрока, рычаги, ящики, ключи и
  батарейки, проходные порталы, конвейеры, лёд, хрупкий пол, лазеры и зеркала, стражи,
  таймерные двери, твёрдое эхо, высота и лифты, обратное эхо.
- Детерминированная симуляция на чистом TypeScript, решатель уровней, встроенный редактор.
- Графика, звук и музыка генерируются кодом; внешних ассетов нет (кроме шрифтов из `@fontsource`).
- ПК (мышь + клавиатура), телефоны и планшеты (тач), геймпад. PWA: устанавливается и работает офлайн.
- Русский и английский языки.

## Требования

Node.js 20+ и npm.

## Команды

| Команда           | Что делает                                                                                            |
| ----------------- | ----------------------------------------------------------------------------------------------------- |
| `npm install`     | установка зависимостей                                                                                |
| `npm run dev`     | дев-сервер (Vite)                                                                                     |
| `npm run build`   | проверка типов и продакшен-сборка в `dist/`                                                           |
| `npm run preview` | локальный сервер для собранной игры                                                                   |
| `npm test`        | тесты (Vitest): механики, ввод относительно камеры, сохранения, прогон эталонных решений всех уровней |
| `npm run solve`   | решатель: ищет решения всех уровней и пишет `levelM.solution.json`                                    |
| `npm run lint`    | ESLint и `tsc --noEmit`                                                                               |
| `npm run format`  | Prettier                                                                                              |
| `npm run icons`   | сгенерировать иконки PWA в `public/icons/`                                                            |

Решатель: `npm run solve -- w1-3 w1-4` — только выбранные уровни; `--write-par` записывает
найденные копии и тики в `par` уровня; `--changed` решает только уровни без действующего
эталона; `--time 60000` — лимит на уровень (мс); `--improve 5000` — сколько ещё искать ради
меньшего числа тиков.

Сборку можно выкладывать как статический сайт (itch.io, GitHub Pages, свой хостинг): все пути
относительные (`base: './'`).

## Приложения для Android и Windows

- **Android (APK)** — обёртка Capacitor, проект в `android/`. Нужны JDK 21 и Android SDK.
  `npm run build:android` → `android/app/build/outputs/apk/release/app-release.apk`.
  Подпись релиза берётся из `android/keystore.properties` и `android/echo-release.jks`
  (в git не попадают — храните их отдельно: без того же ключа нельзя выпускать обновления).
  Игра на весь экран, экран не гаснет, системная «Назад» — пауза и выход из меню.
- **Windows (EXE)** — обёртка Electron, `electron/main.cjs`. `npm run build:win` → в `release/`
  установщик `ECHO-Setup-<версия>.exe` и портативный `ECHO-Portable-<версия>.exe`.
  `npm run electron` — запустить обёртку без упаковки. F11 или Alt+Enter — полный экран.
- Иконки и заставки для обеих обёрток генерирует `npm run icons`.

Exe не подписан сертификатом, поэтому при первом запуске Windows SmartScreen покажет
предупреждение («Подробнее» → «Выполнить в любом случае»).

## GitHub: Pages и сборки

- `.github/workflows/pages.yml` — при пуше в `main` гоняет линт и тесты, собирает игру и выкладывает
  на GitHub Pages. В настройках репозитория: Settings → Pages → Source: **GitHub Actions**.
- `.github/workflows/release.yml` — собирает APK и Windows-версию. Тег `v1.0.1` создаёт релиз с
  файлами; ручной запуск (Actions → Release → Run workflow) кладёт файлы в артефакты. Для
  подписи APK добавьте секреты `ANDROID_KEYSTORE_BASE64` (содержимое `echo-release.jks` в base64)
  и `ANDROID_KEYSTORE_PASSWORD`; без них APK подписывается отладочным ключом.

## Управление

**ПК:** WASD/стрелки — ход (направления всегда относительно экрана: «вверх» — от вас);
F/Пробел — взаимодействие (рычаг, предмет, гнездо, замок рядом); X — ждать; R — записать эхо;
Z — отменить эхо; Backspace — шаг назад во времени; Esc — пауза; Tab — траектории копий;
H — подсказка; Q/E — поворот камеры на 90°; C — сброс камеры; правая кнопка мыши — вращение,
колесо — зум, средняя кнопка — сдвиг; Enter — «Дальше» на экране победы. Все клавиши
переназначаются в настройках.

**Телефон:** свайп — шаг (удерживайте палец, чтобы идти дальше), тап по полю — ждать, два
пальца — вращение и зум камеры. В настройках есть экранный D-pad («Кнопки вместо свайпов»).

**Геймпад:** стик/крестовина — ход, A — взаимодействие, X — записать эхо, Y — отменить, B — шаг
назад, правый стик — камера, бамперы — поворот, Start — пауза. В меню — навигация крестовиной.

## Структура

```
src/
  core/        симуляция: типы, step(), механики, формат уровня, сессия, решатель — без DOM и Three.js
  render/      Three.js: сцена уровня, материалы, шейдеры, частицы, постобработка, отладочный 2D-рендер
  camera/      орбитальная камера, доводка к 45°, перевод экранного ввода в сеточный
  input/       клавиатура, мышь, тач-жесты, геймпад, переназначение клавиш
  audio/       синтезатор на Web Audio, звуки событий, процедурная музыка
  ui/          экраны, HUD, роутер, стили
  editor/      редактор уровней и воркер решателя
  game/        игровой цикл (фиксированный шаг + интерполяция), прогноз петли
  data/        сохранения, прогресс, загрузка уровней
  i18n/        ru, en
  levels/      JSON уровней и эталонные решения
tools/         solver.ts, icons.ts, shot.ts (проверка в headless Chrome), offline-check.ts
tests/         тесты
docs/          MECHANICS.md, LEVEL_FORMAT.md, DECISIONS.md
```

`echo-game.html` в корне — исходный 2D-прототип, в сборку не входит.

## Как добавить уровень

1. Создайте `src/levels/worldN/levelM.json` (формат — `docs/LEVEL_FORMAT.md`). Удобнее всего
   нарисовать уровень во встроенном редакторе и нажать «Копировать JSON» или «Скачать файл»;
   затем поправьте `id`, `world`, `index`.
2. Запустите `npm run solve -- <id> --write-par`. Решатель сохранит эталон рядом с уровнем и
   запишет `par`. Если решения нет — переделайте уровень.
3. `npm test` проверит, что эталон проходит. Уровень без проходящего эталона в игру не попадает.

Бонусные уровни: `"bonus": true` и `"starsRequired": N`, файл — например, `levelB1.json`.

## Как добавить механику

1. Добавьте тип приспособления в `Fixture` (`src/core/types.ts`) и в схему легенды
   (`src/core/level.ts`).
2. Создайте `src/core/mechanics/<имя>.ts` с объектом `Mechanic` (интерфейс в
   `src/core/mechanic.ts`): нужные хуки — `blocksEntry`, `interact`, `onEnter`, `emitSignals`,
   `applySignals`, `check` и т. д. Состояние приспособления хранится в регистре клетки
   (`state.cells[cell]`).
3. Впишите механику в реестр `src/core/mechanics/index.ts` (порядок важен для фазы сигналов).
4. Напишите тест в `tests/mechanics/`, добавьте правила в `docs/MECHANICS.md`, а отрисовку — в
   `src/render/levelView.ts` (метод `makeFixture`).

## Проверено

- Юнит-тесты и прогон эталонных решений всех уровней (`npm test`).
- Headless Chrome и Microsoft Edge (Windows): меню, прохождение, звук, редактор и воркер
  решателя, офлайн-режим PWA, эмуляция телефона в портретной и альбомной ориентации.
- Firefox, Safari (iOS) и Chrome на Android на реальных устройствах не проверялись.
